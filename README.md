# Werstics Verify

Privacy-first payment verification and trusted employee notifications for cashless businesses.

## North star

A customer should not have to expose a private payment SMS, account balance, screenshot, or unrelated financial information merely to prove that a business has been paid.

Werstics Verify gives an authorized frontline employee a business-side confirmation of payment and tracks the transaction through its lifecycle.

## v0.1 foundation

- Deterministic payment domain and state machine
- Provider-neutral payment event model
- Transaction matching
- Merchant/employee authorization boundary
- Simulator for development
- Go HTTP API
- PostgreSQL-ready repository structure

The payment provider remains authoritative for financial truth. Werstics Verify never invents a successful payment.
